<br>

It's time to start coding! In `src/pset0/`, you'll find four task modules covering ideas from recursive list processing to object-oriented programming. The final task also contains an extra credit opportunity, which involves experimenting with your own decision-making agent.

1. In [`sum_nested_lists.py`](../src/pset0/sum_nested_lists.py), you'll implement a single recursive function to sum "nested" lists of integers.

2. In [`hosoya_triangle.py`](../src/pset0/hosoya_triangle.py), you'll implement a function that computes the rows of [Hosoya's triangle](https://en.wikipedia.org/wiki/Hosoya%27s_triangle). (You can think of this like a mix between Pascal's triangle and the Fibonacci sequence.) We've also included a helper function that prints out triangles in a readable format, to help you debug your implementation.

3. In [`sentiment_analysis.py`](../src/pset0/sentiment_analysis.py), you'll implement a class that tokenizes and processes English sentences. More specifically, you'll use stateful logic to compute "sentiment" scores and summaries for arbitrary bodies of text.

4. In [`tic_tac_toe.py`](../src/pset0/tic_tac_toe.py), you'll implement a class that stores the state of an ongoing game of Tic-Tac-Toe. You'll also need to look at a few definitions in [`tic_tac_toe_utils.py`](../src/pset0/tic_tac_toe_utils.py). Once your implementation is complete, you can optionally design your own general agent to play Tic-Tac-Toe.
